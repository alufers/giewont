# giewont

Autor: Albert Koczy nr albumu: 13942

Platformowa gra multiplayer typu capture the flag na własnym silniku w C++.

## Uruchomienie

0. Upewnić się że na porcie TCP/UDP 1338 nie słucha żaden inny program (i otwarty jest firewall jeżeli chcemy grać z innymi osobami).
1. Należy uruchomić serwer `giewont_server.exe` (Linux: `./giewont_server`)
2. Uruchomić klient `giewont_client.exe` (Linux: `./giewont_client`)
3. W menu głównym wpisać IP serwera i swój nick.


## Sterowanie

Poruszanie: A, D, spacja.

Zoom: Scroll w myszce

Strzelanie: lewy przycisk myszy.

Rzut granatem: Q

Interakcja (podniesienei flagi, healthkitu): E

Menu debugowania: F11
